Privacy Policy

Last updated 2026-11-18

What this site collects

This site has no accounts, no comment sections and no forms that submit anywhere. It does not run analytics beyond what the host provides. It does not set its own tracking cookies. The gallery's favorites, collections and theme preference are stored only in your own browser (localStorage) and are never sent anywhere. Like any web host, the hosting provider may keep standard server logs such as IP address, browser and requested page for security and operations.

Advertising

If ads are shown on this site, they are always labelled, and any ad network's own policy applies to the data it collects.

Third-party links

Links to GitHub, YouTube, Instagram, Pinterest and project sites such as DropFast leave this site. Those services have their own privacy policies, which I don't control.
